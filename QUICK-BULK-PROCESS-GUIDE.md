# 🚀 Quick Guide: Bulk Processing

## ✅ What's New

1. **Crawl up to 10,000 pages** (was 100)
2. **Select multiple documents** with checkboxes
3. **Process all at once** with one click

---

## How to Use

### Option 1: Process All Pending (Easiest!)

```
1. Go to Documents page
2. Click "Process All Pending" button (green)
3. Wait for completion
4. Done! ✅
```

### Option 2: Select Specific Documents

```
1. Go to Documents page
2. Check the documents you want
3. Click "Process Selected" button (blue)
4. Wait for completion
5. Done! ✅
```

### Option 3: Select All

```
1. Go to Documents page
2. Click checkbox in table header (selects all)
3. Click "Process Selected"
4. Done! ✅
```

## Buttons Explained

### "Process All Pending" (Green Button)
- Finds all pending/failed documents automatically
- Processes them all
- No selection needed
- **Use this most of the time!**

### "Process Selected" (Blue Button)
- Only appears when documents are selected
- Processes only checked documents
- Good for selective processing

---

## Tips

✅ **For large sites:** Use "Process All Pending"  
✅ **For specific pages:** Use checkboxes + "Process Selected"  
✅ **To retry failures:** Filter by status, select all, process
